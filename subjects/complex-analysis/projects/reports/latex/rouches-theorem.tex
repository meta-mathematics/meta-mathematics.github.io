\noindent\textbf{CA-04 / Complex Analysis / Report v1}

\section{Target and import contract}

\begin{theorem}

For a bounded Jordan domain with piecewise smooth boundary, let \(f,g\)
be holomorphic near its closure and satisfy \(|g|<|f|\) on the boundary.
Prove \(f\) and \(f+g\) have the same number of interior zeros, counted
with multiplicity.

\end{theorem}

\subsection{Foundations and permitted imports}

Import the argument principle: for holomorphic h near a bounded
piecewise smooth Jordan domain closure and no boundary zero,
\((2\pi i)^{-1}\oint h'/h\) is the number of interior zeros counted with
multiplicity. It follows from the residue theorem by locally factoring
each zero \(h=(z-a)^m\) u with \(u(a)\ne 0\). The domain has positive
boundary orientation.

\section{Worked orchestration}

\(On|z|=2\) compare \(f=z^{3}\) and \(g=z+1\). Then \(|g|\le 3<8=|f|\).
Thus \(z^{3}+z+1\) has exactly three zeros \(inside|z|<2\), counted with
multiplicity, although no individual root is located.

\subsection{Boundary and hypothesis audit}

With \(f(z)=z\) and \(g(z)=-1\) on the unit circle, only \(|g|\le |f|\)
holds. The endpoint \(z-1\) has a boundary zero. Sense rejects the
missing strict margin; the zero-count homotopy is not admissible.
